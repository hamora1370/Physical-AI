# Review routine

| Cadence | Timebox | Template | What it decides |
|---|---|---|---|
| Session end | 5 min | `NEXT_SESSION.md` | Last verified state and next one action |
| Weekly | 20 min | [Weekly](WEEKLY_TEMPLATE.md) | Which two issues are active next |
| Monthly | 45 min | [Monthly](MONTHLY_TEMPLATE.md) | Are skills retained / code reproducible? |
| Quarterly | 2 h | [Quarterly](QUARTERLY_TEMPLATE.md) | Advance, repeat, or revise the gate |

For each completed review, create a dated copy (example: `docs/reviews/2026-11-01-weekly.md`) or a tracked Issue linking evidence. Templates alone are not evidence of performed reviews.
