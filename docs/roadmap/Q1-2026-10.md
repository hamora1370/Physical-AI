## Scope of Week 1

1. Inventory system and write in `CURRENT_STATE.md`.
2. Choose **one** isolated Linux/ROS environment, record why; do not modify production ERP host settings without reason.
3. Complete official ROS 2 tutorial first node and capture command/output.
4. Run `python -m unittest discover -s tests -v`.
5. Update `NEXT_SESSION.md` with a single next action.

**Selected target for the new, isolated robotics environment (2026-10-23):** Ubuntu **26.04.1 LTS** + ROS 2 **Lyrical Luth** + Gazebo **Jetty** + MoveIt 2 for Lyrical. This is the target stack, **not yet installed or tested**. First verify available hardware/storage and whether the isolation method is native Linux vs a separate WSL2 distro. Isaac Sim 6.1 lists Ubuntu 22.04/24.04, **not 26.04**, so use a dedicated compatible secondary environment later if that workload requires it. References: https://discourse.openrobotics.org/t/ros-2-lyrical-luth-released/55021 ; https://gazebosim.org/docs/jetty/ros_installation/ ; https://moveit.ai/install-moveit2/binary/ ; https://docs.isaacsim.omniverse.nvidia.com/6.1.0/installation/requirements.html .

## Completion rule

No topic is complete merely because a video/course was watched. Link notes, executable output, test evidence and short reflection. If a gate fails, roll incomplete work forward instead of marking done.

## Time allocation

2 hours math/theory, 2 hours implementation, 1 hour review/notes weekly. Keep scope narrow and protect business priorities.
