**Window:** Mon 2026-10-26 → Sun 2027-01-24. **Budget:** ~65 focused hours.
**Exit gate:** reproducible simulated manipulation demo; tested FK/IK; explain frames and main ROS communication patterns.

| Weeks | Topic | Concrete artifact | Gate |
|---|---|---|---|
| 1–2 | Dev environment, Git, ROS 2 basics | environment report, publisher/subscriber/service/action examples | runnable with documented commands |

## Scope of Week 1

1. Inventory system and write in `CURRENT_STATE.md`.
2. Choose **one** isolated Linux/ROS environment, record why; do not modify production ERP host settings without reason.
3. Complete official ROS 2 tutorial first node and capture command/output.
4. Run `python -m unittest discover -s tests -v`.
5. Update `NEXT_SESSION.md` with a single next action.

Suggested stack to **verify locally before installing**: Ubuntu 24.04, ROS 2 Jazzy, Gazebo Harmonic. Compatibility and current releases should be rechecked when moving to new hardware.

## Completion rule

No topic is complete merely because a video/course was watched. Link notes, executable output, test evidence and short reflection. If a gate fails, roll incomplete work forward instead of marking done.

## Time allocation

2 hours math/theory, 2 hours implementation, 1 hour review/notes weekly. Keep scope narrow and protect business priorities.
