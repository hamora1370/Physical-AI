# Year 1 — robot engineering foundations

**Window:** 2026-10-23 to 2027-10-22. **Guide:** 5 focused hours/week.
**Year exit:** a demonstrated and measured safe, low-power manipulation task, with fundamental kinematics, software stack and failure analysis documented.

| Quarter | Window (approx.) | Learning focus | Required demonstration |
|---|---|---|---|
| Q1 | 2026-10-26 → 2027-01-24 | Linux/ROS 2 fundamentals, frames, SE(3), FK/IK, simulation | reproducible simulation and verified FK/IK exercises |
| Q2 | 2027-01-25 → 2027-04-25 | Jacobians, URDF, hardware I/O, control | safe benchtop arm control; basic joint trajectories |
| Q3 | 2027-04-26 → 2027-07-25 | MoveIt, planning, collision, tf2 and diagnostics | simulated planning with obstacles; hardware baseline if ready |
| Q4 | 2027-07-26 → 2027-10-22 | Vision-assisted pick/place, measurements and failure reporting | 3 categories of light objects; measured task completion |

## Required theory

- homogeneous transformations and frame chaining;
- FK / numeric IK, including unreachable configurations;
- Jacobian basics and singularity awareness;
- feedback concepts, trajectory profiles, actuator constraints;
- collision-free planning vs execution;
- safe bench operations and independent stops.

## Boundaries

A leader/follower educational arm can be added after Q1 if procurement is justified. Do not assume a particular open-source arm has out-of-the-box support for MoveIt or ros2_control.

## Evidence

- Explain each concept from a blank page.
- At least one executable example with automated tests per major math topic.
- Simulation demo including launch/run steps, measured results and limitations.
- Failures documented with root cause hypotheses.
