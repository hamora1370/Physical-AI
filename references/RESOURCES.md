## Resource intake rule

Every suggested book/course/paper needs: source URL, relevant quarterly gate, specific chapter, expected artifact and estimated time. Resources without a current gate go to a backlog Issue instead of the active sprint.

## License and access
Honor course, dataset, model, media and robot design licensing. Never assume a tutorial license authorizes commercial distribution.
